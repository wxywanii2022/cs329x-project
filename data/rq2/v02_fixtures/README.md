# v0.2 regression fixtures for the RQ2 simulator

Eleven hand-built decision points in the RQ2 task format (task assignment as an
`evidence` record, then learner and task-agent turns), labeled by hand under the
frozen codebook v0.2. Generated by `scripts/build_v02_fixtures.py`; edit the
script, not these files.

| File | Contents |
| --- | --- |
| `items.jsonl` | 11 label-free `tutor-assess` items, one behavior each |
| `reference.csv` | Expected v0.2 label and a one-line reason per item |

Purpose: check that the shared assessor applies the RQ1 rules to simulator-style
dialogues before any RQ2 run, especially the B1/B2 N/A-versus-0 boundary. They are
constructed cases, not a sample, so they are not evidence of assessor accuracy, and
they are not part of the RQ1 Main 1 reference.

```bash
tutor-assess run --items data/rq2/v02_fixtures/items.jsonl --config configs/v2/assessment.qwen38-27b-fp8.json \
  --output outputs/rq2-fixtures-<model>
tutor-assess evaluate --run outputs/rq2-fixtures-<model> --reference data/rq2/v02_fixtures/reference.csv \
  --reference-provenance synthetic-fixture --save outputs/rq2-fixtures-<model>/vs-fixtures.json
```
